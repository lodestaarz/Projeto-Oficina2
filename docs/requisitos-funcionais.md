***Requisitos Funcionais***
|  |  |  |
|--|--|--|
Requisito |Especificação |Prioridade
RF01|O sistema deve permitir que novos usuários criem uma conta por meio do preenchimento de nome, e-mail e senha.|Alta
RF02|O sistema deve permitir que usuários cadastrados acessem suas contas utilizando suas credenciais.|Média 
RF03|O sistema deve permitir que o usuário se autentique por meio de sua conta Google.|Alta
RF04|O sistema deve manter a sessão do usuário autenticado durante a navegação e permitir o encerramento da sessão por meio da opção de logout.|Alta
RF05|O sistema deve permitir que o usuário visualize suas informações básicas, como nome e e-mail associados à conta.|Média
RF06|O sistema deve disponibilizar uma área visual delimitada na qual o personagem será exibido e poderá se movimentar.|Alta
RF07|O sistema deve apresentar um personagem visual dentro da área de programação, indicando sua posição atual.|Alta
RF08|O sistema deve permitir a movimentação do personagem por meio de botões identificados pelas direções frente, trás, direita e esquerda.|Alta
RF09|O sistema deve permitir que o usuário movimente o personagem utilizando as setas direcionais do teclado.|Alta
RF10|O sistema deve impedir que o personagem ultrapasse os limites definidos para a área de programação.|Alta
RF11|O sistema deve disponibilizar uma opção para retornar o personagem à posição inicial da área de programação.|Alta
RF12|O sistema deve executar os comandos na ordem em que foram organizados, movimentando o personagem de acordo com as instruções selecionadas.|Alta
RF13|O sistema deve armazenar no banco de dados as informações necessárias para identificar os usuários cadastrados e associar suas contas às respectivas atividades.|Alta
